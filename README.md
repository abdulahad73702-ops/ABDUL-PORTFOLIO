# My Portfolio

A single-page, fully responsive personal portfolio website built exclusively with HTML and CSS, as part of my CST assignment.

## Features
- **Semantic HTML5:** Clean and accessible markup.
- **Modern CSS3:** Flexbox and Grid layouts for responsiveness across all devices.
- **Premium Design:** Dark mode aesthetics with glassmorphism, smooth gradients, and elegant typography.
- **Animations:** Custom CSS keyframe animations, hover effects, and scroll-triggered reveal animations.
- **Contact Form:** Ready for future PHP backend integration.

## Project Structure
- `index.html` - The main portfolio page
- `css/style.css` - External stylesheet containing all design rules
- `images/` - Contains placeholder project thumbnails and profile picture

## How to View
Simply open `index.html` in any modern web browser to view the portfolio locally.
